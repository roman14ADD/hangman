# Hangman — Виселица (Apple-стиль)

Минималистичная игра «Виселица» с дизайном в стиле Apple. Чистый HTML/CSS/JS, без фреймворков.

## Локальный запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/hangman-apple.git
   ```
2. Откройте файл `index.html` в любом современном браузере.

## Деплой на GitHub Pages

1. Загрузите проект в репозиторий GitHub.
2. Перейдите в **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from branch**.
4. Укажите ветку `main` и папку `/ (root)`.
5. Нажмите **Save**. Через минуту игра будет доступна по адресу `https://your-username.github.io/hangman-apple/`.

## Особенности

- Работает на любых устройствах (mobile + desktop)
- Поддержка ввода с физической клавиатуры
- Минималистичный дизайн в стиле Apple (тёмная тема, скругления, стеклянные панели)
- 50+ слов на русском языке

## Технологии

- HTML5
- CSS3 (Flexbox, Grid, backdrop-filter, анимации)
- Vanilla JavaScript (ES6+)
